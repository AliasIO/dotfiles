# Public-facing copy

Reuse [shared marketing context](../_shared/marketing-context.md), the supplied draft, and the project's voice. Ask only for missing facts that change the requested copy. A small edit does not need a new positioning exercise, full page rewrite, alternatives, or annotations.

## Select the work

- **Draft or substantial rewrite:** identify the reader, actual offer, desired action, and available proof. Write only the requested surface. For a full page, use [page and CTA structure](references/drafting.md); consult [copy frameworks](references/copy-frameworks.md) only if a matching pattern helps.
- **Focused edit or review:** keep the author's intent and requested scope. Use [editing and content refresh](references/editing.md) for fact/voice consistency, stale claims, and the specific requested improvement. Preserve untouched sections.
- **Humanization:** apply [voice and clarity](references/voice-and-clarity.md) as a short editing pass. Do not add opinions or personality the author did not express. An explicit request to humanize other text authorizes this bounded pass without turning that text into marketing copy.

## Evidence and delivery

Treat product behavior, plan limits, prices, dates, testimonials, quotes and performance claims as facts to verify or preserve from authoritative context. Never turn example numbers, guarantees or conversion hypotheses into actual product claims. Keep proposals distinct from shipped behavior.

Preserve a supplied template and voice. Return the requested copy; add alternatives or a brief rationale only when requested or useful for a consequential choice. For an implementation request, edit the actual target files and follow project validation and delivery rules. Sending or publishing copy requires matching authorization.

Before delivery, make one brief [voice and clarity](references/voice-and-clarity.md) pass. Fix concrete issues instead of scoring the prose, simulating an approval panel, or repeating the same draft through multiple skills. Use `cro` when the task is to diagnose conversion across a page, signup, or activation flow rather than edit wording alone.
