# KPI design and targets

First establish the decision, intended outcome, controllable levers and operating cadence. Reuse current authoritative definitions. If the task is a disagreement between existing totals or sources, reconcile the data before inventing a new metric definition.

Compare candidate outcome, driver and guardrail metrics by relevance to the goal, useful signal at the decision cadence, available levers, measurement reliability and resistance to gaming. Choose the smallest set that changes decisions. A proxy needs an explanation of what it captures and what it misses; a fixed count or self-assigned scoring threshold is unnecessary.

For each selected metric, specify the definition/formula, population and grain, inclusion/exclusion rules, numerator/denominator where applicable, time treatment, source/owner, refresh cadence, decision it supports and important limitations. A measurement plan should identify missing instrumentation and how it will be validated; it does not authorize implementation or ongoing monitoring by itself.

Select guardrails for plausible harmful tradeoffs, such as lead quality, retention, trust, reliability, acquisition cost or support burden. Do not add unrelated compliance or fairness checklists to every metric proposal.

## Targets

Metric choice and target setting are separate judgments. Set a target when requested or needed for the decision. Anchor it in comparable historical data, a relevant external benchmark, available capacity, planned intervention or an explicit business requirement. Verify changing external benchmarks before use and preserve the user's actual target instead of silently replacing it.

For a bottom-up target, show population × attainable adoption/rate × impact where those factors apply. For top-down goals, compare ambition with observed variability, addressable population and feasible levers. State units, deadline, assumptions and confidence. If support is weak, provide a provisional range or the measurement needed to set a defensible target; never present an invented threshold as established policy.

A concise recommendation can include the chosen metric, why it fits, how to measure it, the target basis if one exists, and the guardrail that changes interpretation. A full report is optional unless requested.
